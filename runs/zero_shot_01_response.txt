To solve this problem, we need to analyze the data from the `stix_flares.csv` file to determine the percentage of strong flares (M and X classes) over time. The solution involves several steps: loading and preprocessing the data, filtering the relevant time period, calculating the monthly counts of strong flares, and generating a plot of the strong flare percentage over time.

### Approach
1. **Load Data**: Read the CSV file containing the flare data.
2. **Convert Timestamp**: Convert the `peak_UTC` column to a datetime object for proper time handling.
3. **Filter Time Period**: Restrict the data to the period from February 1, 2021, to February 28, 2026 (using March 1, 2026, as the end for inclusivity).
4. **Handle Missing Values**: Drop rows with missing `GOES_class_time_of_flare` values.
5. **Identify Strong Flares**: Create a binary indicator for flares that are either M or X class.
6. **Group by Month**: Calculate monthly counts of total flares and strong flares.
7. **Compute Percentages**: Determine the percentage of strong flares for each month.
8. **Print Key Results**: Display important statistics such as total flares, strong flares, and monthly percentages.
9. **Generate Plot**: Create a line plot showing the percentage of strong flares over time and save it to the specified output directory.

### Solution Code
```python
import pandas as pd
import matplotlib.pyplot as plt
import os

# Create output directory if it doesn't exist
os.makedirs('outputs/zero_shot_01', exist_ok=True)

# Load the data
df = pd.read_csv('data/raw/stix_flares.csv')

# Convert 'peak_UTC' to datetime
df['peak_UTC'] = pd.to_datetime(df['peak_UTC'])

# Filter for the time period: from 2021-02-01 to 2026-02-28 (inclusive of Feb 2026)
df = df[(df['peak_UTC'] >= pd.Timestamp('2021-02-01')) & (df['peak_UTC'] < pd.Timestamp('2026-03-01'))]

# Drop rows with missing class
df = df[df['GOES_class_time_of_flare'].notnull()]

# Create strong indicator (1 for M/X, 0 otherwise)
df['strong'] = df['GOES_class_time_of_flare'].apply(lambda x: 1 if x.upper() in ['M', 'X'] else 0)

# Create month string (YYYY-MM)
df['month_str'] = df['peak_UTC'].dt.strftime('%Y-%m')

# Group by month and compute counts
monthly_total = df.groupby('month_str').size()
monthly_strong = df.groupby('month_str')['strong'].sum()

# Create results dataframe
results = pd.DataFrame({
    'month': monthly_total.index,
    'total_flares': monthly_total,
    'strong_flares': monthly_strong,
    'strong_percentage': (monthly_strong / monthly_total) * 100
})

# Print key results
print(f"Total flares in period: {df.shape[0]}")
print(f"Total strong flares: {df['strong'].sum()}")
print(f"First month: {results.iloc[0]['month']}, total flares: {results.iloc[0]['total_flares']}")
print(f"Last month: {results.iloc[-1]['month']}, total flares: {results.iloc[-1]['total_flares']}")
print(f"Strong percentage in first month: {results.iloc[0]['strong_percentage']:.2f}%")
print(f"Strong percentage in last month: {results.iloc[-1]['strong_percentage']:.2f}%")

# Plot the strong flare percentage over time
plt.figure(figsize=(10, 6))
plt.plot(results['month'], results['strong_percentage'], marker='o', linestyle='-')
plt.title('Percentage of Strong Flares (M and X) over Time')
plt.xlabel('Month')
plt.ylabel('Percentage (%)')
plt.grid(True)
plt.savefig('outputs/zero_shot_01/strong_flare_percentage.png')
plt.close()
```

### Explanation
1. **Data Loading and Timestamp Conversion**: The CSV file is loaded into a DataFrame, and the `peak_UTC` column is converted to a datetime object to facilitate time-based filtering.
2. **Time Period Filtering**: The data is filtered to include only flares from February 1, 2021, to February 28, 2026. This ensures we analyze the specified time window.
3. **Handling Missing Values**: Rows with missing `GOES_class_time_of_flare` values are dropped to avoid errors in classification.
4. **Strong Flare Identification**: A binary indicator (`strong`) is created where `1` means the flare is either M or X class (case-insensitive).
5. **Monthly Aggregation**: The data is grouped by month (formatted as `YYYY-MM`), and counts of total flares and strong flares are computed for each month.
6. **Percentage Calculation**: The percentage of strong flares for each month is calculated by dividing the count of strong flares by the total flares and multiplying by 100.
7. **Key Results Printing**: The solution prints key statistics including the total number of flares in the period, total strong flares, and the strong flare percentages for the first and last months.
8. **Plot Generation**: A line plot is generated showing the percentage of strong flares over time. This plot is saved to the `outputs/zero_shot_01` directory for later review.

This approach ensures that we efficiently process the data, derive meaningful insights, and present the results in a clear and actionable format. The solution handles edge cases such as missing values and time period filtering to ensure robustness.
